# Security policy

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities in a public issue. If GitHub
private vulnerability reporting is enabled for this repository, use it to
contact the maintainers. Otherwise, contact the repository owner privately
before sharing technical details.

## Data and models

The application processes local images and stores job state and reports in
the selected output folder. Do not attach real customer photographs, printer
ICC profiles, local configuration, or generated files to public bug reports.
Model downloads are verified against a pinned SHA-256 digest.
